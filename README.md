# 🔄 Loop

یک فضای کاری هوشمند: از اسکچ تا خروجی، در یک فایل.

**[🚀 امتحان کن](https://aliarkan4772-cloud.github.io/loop/)**

![License](https://img.shields.io/badge/license-MIT-green)
![Made with](https://img.shields.io/badge/made%20with-vanilla%20JS-yellow)

## چیه؟

Loop یه وب‌اپ مینیماله که چرخه‌ی کامل کاریت رو در یک فایل می‌سازه:

1. ✍️ **اسکچ** روی بوم بی‌نهایت
2. ⇄ **تبدیل** به مارک‌داون
3. ❓ **پرسش** از سند
4. 📄 **خروجی** PDF یا PNG

بدون سرور. بدون ثبت‌نام. کاملاً محلی.

## چرا؟

- 🔐 **حریم خصوصی:** همه‌چیز تو مرورگر خودته
- ⚡ **سریع:** پردازش محلی، صفر تاخیر
- 📦 **یک فایل:** فقط یه HTML، بدون وابستگی
- 💸 **رایگان:** برای همیشه

## نصب

```bash
# فقط دانلود کن
git clone https://github.com/aliarkan4772-cloud/loop.git

# باز کن توی مرورگر
open index.html
```

## قابلیت‌ها

- بوم بی‌نهایت با زوم و pan
- یادداشت، چک‌لیست، شکل، رسم آزاد
- تبدیل هوشمند به مارک‌داون
- استخراج اکشن آیتم‌ها
- خلاصه‌سازی متن
- پرسش از سند با منبع
- خروجی PDF (A4 با واترمارک شمسی)
- خروجی PNG
- سینک بین تب‌ها

## تکنولوژی

- HTML, CSS, Vanilla JavaScript
- Canvas API
- BroadcastChannel API
- LocalStorage
- بدون فریم‌ورک، بدون بیلد، بدون وابستگی
